Папка «Телевизор» лежит на рабочем столе целиком
================================================

Не вытаскивайте файлы из этой папки по одному.
Не раскладывайте их рядом на рабочем столе.
Папка должна называться «Телевизор» и лежать на рабочем столе как одна папка.

Внутри уже есть всё, что нужно для чистки и для отката.
Сюда же позже кладётся папка platform-tools. Это программа adb,
без неё компьютер не разговаривает с телевизором.


Что делать по порядку
=====================

Сначала программы с пульта. Компьютер для этого не нужен.
Памятка на телефоне ведёт по шагам: магазин, Кинопоиск, Музыка,
Happ, YouTube, Netflix.

Правило каждый вечер:

- YouTube и Netflix: сначала включить Happ.
- Кинопоиск и Музыка: сначала выключить Happ.
  Музыка находится внутри Кинопоиска.

Компьютерная чистка нужна только если после этого телевизор
всё ещё тяжёлый. Она выключает рекламу и встроенный очиститель.
Кинопоиск, Музыку, Happ, YouTube, Netflix, пульт, каналы,
магазин и главный экран она не трогает.


Один раз подготовить компьютер
==============================

1. Поставьте Python с сайта python.org.
   В начале установки поставьте галочку Add python.exe to PATH.

2. Скачайте Android SDK Platform-Tools с сайта developer.android.com.
   Это обычный zip. Распакуйте его так, чтобы получилось:

   Рабочий стол
     Телевизор
       platform-tools
         adb.exe

   Файл adb.exe должен лежать внутри platform-tools,
   а platform-tools внутри «Телевизор». Не на рабочем столе отдельно.
   Рядом с adb.exe должен лежать файл AdbWinApi.dll.
   Один adb.exe из архива не вытаскивайте.

3. Компьютер и телевизор в одной сети ASUS_359.
   Кабель или Wi‑Fi, не мобильный интернет.


Один раз открыть дверь на телевизоре
=====================================

1. Настройки, значок шестерёнки.
2. Об устройстве. Это то же меню, что на вашем фото.
3. Внизу строка «Сборка». Нажмите ОК семь раз.
   Появится надпись, что вы стали разработчиком.
4. Назад. Откройте «Для разработчиков».
5. Включите «Отладка по USB».
   Если есть «Отладка по сети», включите и её.

Если пункта «Для разработчиков» нет, остановитесь и пришлите фото.
Заводские меню и коды с цифрами не открывайте.

Адрес телевизора: Настройки, Сеть, IP-адрес.
Берите короткую строку, она начинается с 192.168.
Длинную строку с буквами fe80 не берите.
На фото был 192.168.50.65. Если сейчас написано другое, берите новое.


Снимок, телевизор ещё не меняется
=================================

1. Откройте папку «Телевизор» на рабочем столе.
2. Дважды щёлкните файл «Снимок.bat».
3. Чёрное окно версии 2 само не закрывается.
   Первая строка в нём должна быть: Версия 2.
   Если окно закрылось от одной клавиши, это ещё старый файл.
   Впишите адрес целиком, например 192.168.50.65,
   и только потом нажмите Enter.
   Чтобы закрыть окно, напишите слово выход и нажмите Enter.
4. Если телевизор спросит «Разрешить отладку по USB?»,
   на пульте нажмите ОК. Потом закройте чёрное окно
   и ещё раз щёлкните «Снимок.bat».
5. Прочитайте, что написано в окне.
   Там список рекламы, которую можно выключить.
   Телевизор при этом ещё старый.

В папке появится новая папка «откат».
Её не удаляйте. В ней снимок и файл ВЕРНУТЬ.


Выключить рекламу
=================

Щёлкните «Применить.bat» и снова вставьте тот же адрес.
После этого выключите на телевизоре отладку:
Для разработчиков, «Отладка по USB» и «Отладка по сети» снять.

Проверьте пульт, кнопку выбора входа HDMI, Кинопоиск и YouTube.
Если что-то стало плохо, сразу делайте откат. Инструкция в ОТКАТ.txt.
