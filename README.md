# Чистка телевизора SSMART 43FSV22

Здесь лежит папка **Телевизор**. Её нужно целиком положить на рабочий стол компьютера.

Не вытаскивайте файлы из папки по одному.

Сначала откройте файл `Телевизор/СНАЧАЛА ПРОЧИТАЙТЕ.txt`.

Как скачать:

1. На этой странице нажмите зелёную кнопку **Code**.
2. Нажмите **Download ZIP**.
3. Распакуйте архив.
4. Папку `Телевизор` из архива скопируйте на рабочий стол.

Кинопоиск, Музыка, Happ, YouTube, Netflix, пульт, каналы, магазин и главный экран не удаляются. Если станет хуже, запустите `Откат.bat`.
